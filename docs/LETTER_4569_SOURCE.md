## 提取范围和准确性

从 16.77 秒视频末帧（信纸展开后）人工核对可辨认的原文，**只选取能够可靠辨识的句子**，不将难以辨认的笔画假装已识别，也不自动生成缺失的字句。第五页署名仍属于原作者，不归属绘本作者。收信人昵称没有复制进公开仓库。

按原信情绪递进自然切分为五个双页章节：

1. **HELLO** — “见字如面，展信舒颜！”“当你读到这封信的时候，我在你们世界会不会多停留一封信的时间^^。”
2. **GROW** — “最近过得好吗？”“也非常开心你能喜欢听我唱歌！”
3. **TOGETHER** — 原信表达“被记住的惊喜，以及成为对方生活中快乐的一部分”。其中页面标题“能被你记住，真的很开心。”是**明确的编辑性提炼**，不标注为逐字原文；正文“我能成为你生活中快乐的一部分，真是太好啦！”。
4. **DREAM** — “愿你在平凡的日子里，也能遇见温柔的风，明亮的时光，和不期而遇的欢喜。”
5. **WISH** — “希望我的歌声可以为你带来温暖。”“今后也请姐姐多多关照啦 ♡”。

**范围说明：** 这是选段编排，不是未经校对的全文誊写。原视频包含其他涉及具体人名或近况的段落，当前未写入公共展示页。完整视频仍保留在私有项目。未来若需要逐字全文展出，应先逐行核对不清楚的手写内容。

- 普通祝福独立地址：`?story=letter`。这是整本书的单独故事模式，仍有封面→五章→正反翻页，且**不会无端插入“生日快乐”**。
