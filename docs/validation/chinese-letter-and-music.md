# 中文来信与配乐验收

基线为 AWS `9f8ca9f`。默认地址和原来信地址统一进入中文版《一封来信》。来信页收起生日版入口，显式 `?story=birthday` 与已有 `#gift=` 仍打开生日绘本。保留真实笔迹与署名。封面使用同一套夜景与烫金边框，五章背景标题沿用原有颜色、纹理及图层，以 Noto Serif SC 的矢量字形替换英文字。

配乐选用 Scott Buckley 的《The Long Way Home》，由作者按 CC BY 4.0 提供。本地 MP3 保留全曲，下调 8 dB 并重新编码为 80 kbps。曲目和许可在网站页脚与 `public/audio/CREDITS.txt` 署名。打开时尝试播放，浏览器拦截时在首次点按或翻页后重试。翻页时沿用同一进度，手动暂停后后续翻页保持静音。

浏览器对照沿用已发布版的画幅、原画和书页位置。检查 1440×900、390×844、320×680 和横屏 844×390，比较封面与内页。去掉窄封面上和底部题字过近的第二行副文案。开合、0/25/50/75/100% 姿态、双向连续录像和前后对照保存在本机 `test-results/chinese-letter/`。音乐验收使用浏览器实际播放时间、请求和暂停状态。真实 iPhone Safari 单独验收。
